# 📝 Java REST API

A simple RESTful API built to learn **Spring Boot**, **Spring Data JPA**, and **Spring Security**.  
This project allows users to interact with entities via REST endpoints, demonstrating how controllers, services, repositories, and database integration work together in a backend API setup.

> 🧠 **Note:**  
> This project follows a **RESTful API architecture** with Spring Boot.  
> It is intended for **educational purposes** — to understand building secure, documented, and testable APIs before integrating with frontends like React or Angular.

---

## ⚙️ Technologies Used

- ☕ **Java 21**  
- 🧩 **Spring Boot 4.0.1**  
- 🗄️ **Spring Data JPA**  
- 🔐 **Spring Security**  
- 🧪 **Spring Boot Starter Test**  
- 📄 **Springdoc OpenAPI / Swagger UI**  
- 🖥️ **H2 In-Memory Database**  
- 🐬 **MySQL Connector**  
- ⚡ **Spring Boot DevTools**  
- 🌐 **Spring Boot Starter HATEOAS**  
- 📊 **Spring Boot Actuator**

---

## ✨ Features

- 🔐 Basic security with Spring Security  
- ✅ CRUD operations on all entities via REST endpoints  
- 🌐 HATEOAS-enabled responses for resource navigation  
- 📄 Auto-generated API documentation with Swagger/OpenAPI  
- 🗄️ Support for H2 in-memory database and MySQL for persistence  
- 🧪 Unit and integration tests included  
- ⚡ Monitoring and metrics with Actuator
